# Mi Portafolio Personal

Portafolio personal que muestra información sobre mí y formas de contacto.

## Tecnologías Utilizadas

- HTML5
- CSS3
- Responsive Design

## Características

- Diseño moderno y limpio
- Totalmente responsive
- Paleta de colores personalizada
- Tipografía moderna

## Instalación

No se requiere instalación. Solo abre el archivo `index.html` en tu navegador favorito.

## Personalización

Para personalizar este portafolio:

1. Reemplaza la imagen de perfil en `index.html`
2. Modifica la información personal y de contacto
3. Ajusta los colores en `css/style.css` (variables CSS en `:root`)
4. Cambia las tipografías en los enlaces de Google Fonts
